## 1. IOBOARD_D (ids 420–439)

- Every light registered by `LC_AddLight` (note: `lightctrl.h` has `NUM_OF_LIGHTS 4`, `CLAUDE.md` says 11 light
  outputs — **the code wins**; report which outputs are lights): intensity 0–100 %, `uint32`, `power_w: 12`.
- Sewage pump (`SEWAGE_PUMP_OUTPUT`, `APP.c`): `bool` on/off.

## 2. ELECON_D (ids 490–509)

- Axpert (REL1) and Victron (REL3): AC state machine state, enum `ACState`
  {0: Off, 1: On, 2: OnKeepSetting, 3: KeepOn, 4: AutoOff} (= `eACState` in `AC.h`; one YAML enum shared with ELECON).
- Akupack heater relay (REL2): `bool`.
- Akupack heater setpoints: `AkupackHeatingControl()` in `APP.c` has local `reqTemp = 10.0f` (day) / `7.0f`
  (night). Make them two static module variables (same values), publish both as `float` °C
  (`AkupackSetDay_C`, `AkupackSetNight_C`). They become settable in step 3.
- EVSE relay (OUT1): `bool`.
- Exterior light (OUT2, PWM): 0–100 %.
- Lights Kolarna and Sklep (`lightctrl`): 0–100 %, `power_w: 12`.
- Not published: OUT3 (unused), OUT4 (reserved).

## 3. ELECON (ids 480–489)

- Inverters AC300W, AC3kW, AC5kW (REL1–3, `AC.c`): enum `ACState` (same YAML enum).
- Exterior light (`ExtLightControl()` in `APP.c`): 0–100 % (or bool if the code only switches on/off — say which).

## 4. RECU (ids 510–519, `ASW_RECU_NUCLEO`)

- First sync `ASW_RECU_NUCLEO/UhaCommon/` with `UHA_COMMON` (VARS2.c/h, VARS2_types.h, generated files) — must be
  identical (`UHA_COMMON/CLAUDE.md`).
- Remote request mode (`mRemoteMode`, `eRecuRemoteReqMode` in `RECON.c`): enum `RecuRemoteMode`
  {0: Auto, 1: SlightOverpressure, 2: MaxOverpressure, 3: SlightUnderpressure, 4: MaxUnderpressure}
  (take the real order from the enum in the code).
- Active limitation: one enum `RecuLimit` with the highest-priority limitation that is active in this cycle of
  `RECON` — values from what the code really has (battery off < 30 % SOC, eco < 85 % SOC, antifreeze, anti-dry
  `mAntiDryOn`, none). Document the mapping in the YAML comment. Do not restructure `RECON`; set the value where
  each branch is taken.
